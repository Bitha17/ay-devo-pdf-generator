📋 .docx format guide

Plain paragraphs — no field labels, no tables. First paragraph is the week's title, then one block per day:

Semakin Mengenal dan Menyembah Dia   ← week title (paragraph 1, once)

Senin                                 ← day name (Indonesian)
Allah yang Layak Disembah             ← that day's theme
Mazmur 96:1–9                         ← bible reference

Konteks
Mazmur ini adalah sebuah nyanyian pujian yang menegaskan…

Firman Kristus
Mazmur ini mengajarkan bahwa Allah adalah Pribadi yang…

Pertanyaan
Dari bacaan ini mengapa seluruh bumi sepatutnya menyembah…
Coba renungkan, apakah kehidupan saudara sudah memuliakan Allah?
Bagaimana saudara dapat menyembah Allah dalam kehidupan sehari-hari?

Selasa                                ← next day, same shape
…

Repeat the day block for every day of the week, in order — Senin, Selasa, Rabu, Kamis, Jumat, Sabtu, Minggu. Each question is its own paragraph (no manual numbering — the PDF and web view number them automatically). Blank lines between paragraphs are fine and ignored.

Since the docx has no calendar dates, the Week start date field below is required — it's assigned to the first day block, and the rest follow in order.

Inline formatting

Bold and italic text applied in Word carries through to both the PDF and the web view, but only within Konteks and Firman Kristus — just select the text and use Word's normal Bold/Italic formatting there. Pertanyaan (and the theme/verse lines) are kept plain even if formatted, since those are short structured lines where it isn't meaningful.
